AURA Desktop IDE

Windows 10 / 11 · 64-bit

Install AURA Desktop IDE

One small setup file. Every time you run it, it installs the newest build — so the copy you download today still installs tomorrow’s version.

Download setup file AURA-Desktop-Setup.cmd

This device does not look like Windows. AURA Desktop IDE is Windows-only for now — open this page on your Windows PC.

How it works

  1. Download

    Save AURA-Desktop-Setup.cmd. Your browser may ask you to confirm keeping it — that is normal for script files.

  2. Run it

    Double-click the file. If Windows says it protected your PC, choose More info, then Run anyway: the setup file is not code-signed yet.

  3. Done

    It finds the newest build, downloads it, checks its SHA-256 checksum and starts the installer. No administrator rights needed.

Early access

While AURA’s source repository is private, setup needs a GitHub account that can read it. Install the GitHub CLI and run gh auth login once — setup picks the sign-in up by itself. Alternatively set an AURA_GITHUB_TOKEN environment variable.

Updating

Run the same setup file again whenever you want the latest version. If you already have it, setup says so and stops; it only reinstalls when there is something newer (or with -Force).

Verify your download

The SHA-256 checksum of the file offered above:

__SETUP_SHA256__

Compare it with your download in PowerShell:

Get-FileHash .\AURA-Desktop-Setup.cmd -Algorithm SHA256

Command-line options

Run the file from a terminal to use these:

OptionWhat it does
-SilentInstall without the installer window.
-ForceReinstall even if you are already on the newest build.
-DownloadOnlyDownload and verify the installer, but do not run it.

Good to know

  • Needs 64-bit Windows 10 or 11 and an internet connection.
  • If the Microsoft Visual C++ runtime is missing, setup installs it first (Windows asks once for permission).
  • The Engineer agent works on Git repositories. If Git is not installed, setup suggests winget install Git.Git.
  • To remove AURA: Settings → Apps → AURA AI → Uninstall.
