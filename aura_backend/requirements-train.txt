# Optional LoRA training dependencies (ADR-008 Loop B, GAP-017).
#
# Deliberately NOT part of requirements.txt / requirements.lock: the gateway never trains, and
# keeping PEFT out of its image is what lets the default trainer (`scripted`) be the only one a
# gateway can run. Only the `training` target of aura_backend/Dockerfile installs this file, and
# only the `worker-training` compose service builds that target.
#
# torch and transformers are already pinned by requirements.lock (sentence-transformers needs
# them); the constraint line below holds them, and every other shared package, at exactly the
# lockfile's versions so the training image cannot drift from the gateway's.
#
#     pip install --require-hashes --extra-index-url https://download.pytorch.org/whl/cpu \
#         -r requirements.lock -r requirements-train.lock
#
# Installs go through requirements-train.lock, the hashed compile of this file (command in
# requirements-dev.txt); edit this file, then regenerate that lock.
#
# Verified (2026-09-25) in a separate venv with Python 3.11 against
# hf-internal-testing/tiny-random-gpt2 on CPU -- see tests/training/test_lora_weights_change.py
# (opt-in: `pytest tests/training -m training`).
-c requirements.lock
