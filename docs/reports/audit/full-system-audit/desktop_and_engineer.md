## 1. Scope and method

In scope: the backend host-agent bridge (`aura_backend/aura_core/api/host_agent.py`,
`adapters/host_agent.py`, `api/ws_auth.py`), desktop pairing and device tokens
(`services/device_pairing.py`, `services/jwt_auth.py`, `api/v2/auth.py`), the Engineer tool
surface and its policy (`tools/coding.py`, `tools/policy.py`, `tools/registry.py`,
`agents/registry.py`, `kernel/kernel.py`), server-side Engineer workspaces (ADR-013/014:
`adapters/docker_sandbox.py`, `container.py`, compose socket-proxy settings), the daemon
`aura_hostd/` (all 18 `lib/src/*.dart` files were listed; `containment.dart`, `command_policy.dart`,
`task_handler.dart`, `rpc_client.dart`, `control_server.dart`, `approval_queue.dart`,
`isolated_task_registry.dart`, `config.dart`, `workspace_store.dart`, `bin/aura_hostd.dart` read in
full; `git_service.dart`, `terminal_session_manager.dart`, `posix_pty_session.dart` read in part),
and the Flutter desktop client surfaces (`aura_client/lib/desktop/**`, `lib/core/hostd/**`,
`lib/core/platform/aura_platform.dart`, `lib/core/config/config.dart`,
`lib/core/ai/online_agents/sse_agent_client.dart`, `macos/Runner/Release.entitlements`).

Method: code read with `path:line` citations (label `CODE-READ`). Read-only git one-liners were
run (`git log`, `git ls-files`, `git check-ignore`; see §6). **Nothing was executed**: the host's
`C:` drive is full, so `dart test`, `flutter test` and `pytest` were `NOT RUNNABLE` in this
environment (they write caches/temp to `C:`), and GitHub Actions has no runners (CB-44). Every
behavioral claim below is therefore `CODE-READ` or `CODE-PRESENT / BEHAVIOR UNVERIFIED` unless
marked otherwise. Production state (Railway) could not be probed.
