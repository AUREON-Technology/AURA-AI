Whether production sets `AURA_ENGINEER_AGENT_ROLES` is UNKNOWN (cannot probe). The app has no caller for `/auth/desktop/devices/revoke` (§2.2), so a paired daemon can only be cut off by the app's own session revocation or token expiry. — E2-05.
