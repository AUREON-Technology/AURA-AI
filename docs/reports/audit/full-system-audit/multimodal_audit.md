### 2.3 Security properties observed (CODE-READ, positive)

- Image type decided by magic bytes, pixel count checked before decode, metadata dropped by re-encoding, first frame only, never upscaled (`pillow_images.py:288-331`).
- Image bytes never logged (`domain/images.py:368-382`); never persisted (`kernel.py:1144-1153`); image turns skip the response cache (`kernel.py:2065`).
- Images never reach text-only or third-party providers regardless of hint (`router.py:309-316`); never sent as URLs (`providers/base.py:89`).
- Perception is DATA-channel caller context (fenced, guarded, tainting) and the turn starts SENSITIVE (`vision/engine.py:196-201`, `kernel.py:1141, 1167-1168`).
- Service keys cannot attach images (`v3.py:504-508`).
- Live voice: service keys cannot open the socket (`v3.py:1631-1636`); reauth cannot switch user (`voice_live.py:254-258`); confirmation is by server-held approval id, never by tool name (`session.py:165-187`).
- espeak voice codes are regex-validated against shell-like tokens (`espeak_tts.py:239, 259-264`); Piper text goes over stdin (`piper_tts.py:191`).
